## Color

- One light theme: background white or warm off-white (e.g. `#FFFFFF` / `#FAFAF8`), text near-black (e.g. `#1A1A1A`), borders `#E5E5E5`.
- Print styles follow the same palette with backgrounds removed.

## Rules for agents

- Do not add dark-theme values or a theme switch.
