## Color

- Palette monochrome: background `#FFFFFF` (light) / `#0A0A0A` (dark), surface `#F2F2F2` / `#161616`, text `#0A0A0A` / `#F5F5F5`, muted `#6B6B6B` / `#8F8F8F`, accent = text (emphasis by weight, size, underline or inversion).
- Status colors only where meaning needs them: success `#1F7A3A`, warning `#9A6700`, danger `#C62828`, always with a label or icon.
- Terminal: default foreground/background, bold and reverse video for emphasis; no color besides status.
- These values replace the base palette's for the same roles; contrast pairs are checked again after the swap.
