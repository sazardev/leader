## Color

- Palette phosphor amber: background `#0F0A00`, surface `#1A1205`, text `#FFB000`, muted `#B37A00`, accent `#FFD27F`, success `#FFC94D`, warning `#FFE08A`, danger `#FF5A3C`.
- Terminal: truecolor values above, ANSI fallback yellow (`3`) for text, bright yellow (`11`) for accent.
- Hierarchy by brightness, not hue.
- These values replace the base palette's for the same roles; contrast pairs are checked again after the swap.
