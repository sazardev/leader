## Color

- Palette phosphor green: background `#0A0F0A`, surface `#0F1A0F`, text `#33FF66`, muted `#1F9E40`, accent `#7CFF9E` (bright), success `#33FF66`, warning `#CCFF66`, danger `#FF6B5A` (the only non-green, used rarely).
- Terminal: truecolor values above, ANSI fallback green (`2`) for text, bright green (`10`) for accent, default background.
- Hierarchy by brightness, not hue: bright for focus, normal for text, dim for muted.
- These values replace the base palette's for the same roles; contrast pairs are checked again after the swap.
