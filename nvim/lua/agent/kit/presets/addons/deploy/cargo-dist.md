## Stack

| Release | cargo-dist (`dist`): CI-built archives per target, shell/PowerShell installers, checksums, on every `v*` tag | Release pipeline generated and kept in sync with Cargo metadata |

## Conventions

- Release configuration lives in `Cargo.toml` / `dist-workspace.toml`; the CI workflow is generated by `dist init` and regenerated, not edited by hand.
- Targets: x86_64 and aarch64 for Linux (musl), macOS and Windows.

## Commands

| Release plan | `dist plan` |
| Build artifacts locally | `dist build` |

## Rules for agents

- Never edit the generated release workflow by hand: change the config and run `dist init` again.
- The version comes from `Cargo.toml`; bump it in the release commit.
